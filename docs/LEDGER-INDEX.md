*This file IS the ledger (W-139, ruled by Howell 2026-08-23). Hand-maintained: a ruling gets its
line the hour it is made (WF-2), a status changes by editing that line (WF-6). It lives here, in
team_communication, so either session can file its own numbers without crossing the wall (WF-15);
each repository carries a generated copy at `docs/LEDGER-INDEX.md` so its commit gate can check a
cited number exists, and `scripts/build-ledger-index.mjs` copies and verifies — it never parses
prose again.*

*The prose era — HANDOFF.md, 13,322 lines, and its archives — stays readable in this repository's
git history and is never live again. Before it went dark both sessions swept every OPEN entry
asking one question: does this ruling's substance live anywhere that is READ? What did not, landed
first (docs/ROADMAP.md, engine FEEL.md and DIMENSION_SYSTEM.md, mmdm/README.md, and comments at the
code they bind). "Reachable by blame is not a home." — Orville, whose condition that was.*

*Statuses, five and only five: **RULED** (live doctrine — its substance lives in the home named on
the line) · **DONE** (completed work; the record is the substance) · **OPEN** (genuinely unfinished
— and the title SAYS WHY, because "open" over owed work and "open" over an unruled question look
identical and mean opposite things) · **SUPERSEDED BY <id>** (never bare: an unnamed supersession
cannot be followed, WF-6) · **DECLINED**.*
